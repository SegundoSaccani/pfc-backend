BACKEND:
- guarda relevamientos
- devuelve relevamientos
- devuelve reglamentación
- calcula indicadores
- maneja usuarios/roles
- expone todo por API

WEB:
- consulta relevamientos
- manda filtros
- muestra indicadores
- tablas
- gráficos
- mapa
- exportación

REGLAS GENERALES
- JSON para request/response
- Coordenadas como latitud/longitud
- IDs numéricos
- la web no necesita saber cómo se guarda internamente en PostgreSQL
- los indicadores se calculan en backend (la web solamente los muestra)

Request:

{
  "usuario": "usuario1",

}

Response (ejemplo):

{

RELEVAMIENTOS

POST /api/relevamientos (lo usa la app móvil para sincronizar un relevamiento con el backend)

Request:

{
  "fechaHora": "2026-09-13T18:30:00-03:00",
  "puntoDesembarco": "Puerto de Santa Fe",
  "ubicacion": {
    "latitud": -31.633,
    "longitud": -60.699
  },
  "observaciones": "Sin observaciones",
  "pescadorId": 145,
  "individuos": [
    {
      "especieId": 1,
      "talla": 42.5,
      "confianzaEspecie": null
    },
    {
      "especieId": 1,
      "talla": 45.0,
      "confianzaEspecie": null
    }
  ]
}

Response:

{
  "id": 125,
  "estado": "REGISTRADO"
}

- ver cómo evitar duplicados cuando la app reintenta sincronizar
- definir cómo se mandan/guardan las fotos

GET /api/relevamientos (lo usa la WEB)

posibles filtros:

fechaDesde
fechaHasta
especieId
puntoDesembarcoId
pescadorId
page
size

ejemplo:

GET /api/relevamientos?fechaDesde=2026-09-01&fechaHasta=2026-09-30&especieId=1

{

    {
      "id": 125,
